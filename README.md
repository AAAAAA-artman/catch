# 接住

> 一个关于「听见」的打字游戏。你是被父母反复念叨的孩子，要在压力与麻木之间撑过 30 句话。

Godot 4.7 · GDScript · 1280×720 · 16:9

---

## 这是什么

《接住》是一款**双输入模式的中文打字游戏**。屏幕上飘着一句话，你要原样打出来 —— 打完它，好感度涨一点；打不完，压力涨一截。

游戏分三个阶段，每个阶段 10 句。每过三分之一好感，插入一段剧情。一路走到最后，你会看到这个家的全貌。

支持两种输入方式：

| 模式 | 按键 | 说明 |
| --- | --- | --- |
| **汉字模式** | `1` | 用中文输入法直接打整句汉字，逐字校对 |
| **拼音模式** | `2` | 用英文键盘打拼音（不带声调），音节间按空格 |

## 快速开始

### 需要

- [Godot 4.7](https://godotengine.org/download/)（**标准版**即可，不需要 .NET 版）
- Windows / macOS / Linux
- 系统中文字体（Windows 自带微软雅黑，无需额外安装）

### 运行

```bash
git clone <你的仓库地址>
cd 接住
```

1. 启动 Godot → 「导入」→ 选择本目录的 `project.godot`
2. 按 **F5** 运行项目
3. 标题页按 `1` 或 `2` 开始

### 开发者快捷键

调试时不必从头打，游戏内随时可用：

| 键 | 作用 |
| --- | --- |
| **F1** | 直接开始汉字模式，**跳过开场剧情** |
| **F2** | 直接开始拼音模式，跳过开场剧情 |
| **F3** | 好感度循环跳 `0 → 34 → 68 → 96`（连按轮换） |
| **F4** | 好感度拉满 → 触发结局 |
| **F5** | 时间拉到 5%（看紧张音效和时间条） |
| **F6 / F7** | 压力 / 麻木 +30 |
| **F8** | 重播当前剧情段 |
| **F9** | 打印当前状态到输出面板 |
| **F12** | 免死开关（压力麻木不会导致失败） |

## 玩法

### 核心循环

```
换一句 → 飘字淡入 + 下方逐字浮现 → 你打字 → 打完 / 超时 → 同心圆结算 → 下一句
```

每句限时 = `7 秒 + 1.5 秒 × 字符数`，后半段收紧 15%。

### 三条数值

| 数值 | 满了会怎样 | 怎么涨 | 怎么降 |
| --- | --- | --- | --- |
| **好感度** | 到 100 通关 | 每句打完 +4 左右 | — |
| **压力**（红条） | 到 100 失败 | 负面句 +18、打错 +8、超时 +20 | 正面句 −12 |
| **麻木**（紫条） | 到 100 失败 | 按住 Alt 抵抗时持续 +3 | — |

### 抵抗机制

按住 **Alt** 不放，当前这句话会以 **8 倍速**飞速滑过 —— 你不用打完它。代价是麻木条持续上涨。这是个逃生阀，但用多了会麻木。

### 三个阶段

好感度每满 1/3 进一段剧情，画面也跟着变：

| 阶段 | 好感范围 | 画面 |
| --- | --- | --- |
| **第一段** | 0 ~ 1/3 | 房间照片，**随好感度越来越暗**，模糊度随机切换，带轻微摇晃 |
| **第二段** | 1/3 ~ 2/3 | 青绿房间，门上站着持烛的少年。**进度过半触发跳吓** |
| **第三段** | 2/3 ~ 100 | 一组全家福按好感度**逐张浮现**，第 2 张起铺满全屏 |

剧情段落：`序章 → 第一段游戏 → 第一段后日谈 → 第二段后日谈 → 结尾`。

## ★ 文字特效库（可移植）

`addons/text_fx/` 是一个**完全独立**的中文文字特效库：复制整个目录到任何 Godot 4 项目就能用，不依赖本项目任何资源。

### 它能做什么

5 种曲线 × 各种消失方式，共 19 种预设效果：弧形、圆形、波浪、贝塞尔拱形、直线；逐字浮现、缓慢淡出、飘散、抖动、收缩……完整目录见 [文字特效手册.md](文字特效手册.md)。

### 三行接入

```gdscript
var layer := TextFX.ui_layer(self)                    # 建一层 UI 画布
TextFX.whisper(layer, "门还没有关上", Vector2(640, 300))
TextFX.banner(layer, "接住了", Vector2(640, 200))
```

### 手动控制

```gdscript
var node := CurvedText.new()
node.text = "慢慢消失的一句话"
node.font_size = 48
node.curve_mode = CurvedText.CurveShape.ARC   # STRAIGHT / ARC / CIRCLE / WAVE / BEZIER
node.radius = 900.0                            # 弧线半径
node.rotate_follow = 1.0                       # 字是否跟着切线转
add_child(node)

node.fade_out(3.5, 0.0, 0.45)   # 时长 / 延迟 / 逐字错开
node.fade_in(2.2)               # 反向
node.seek(0.5)                  # 手动定位进度
```

### 关键特性

- **中日韩友好**：自动检测系统字体，中文不会显示成方框
- **逐字控制**：每个字的缩放、旋转、漂移、透明度独立
- **不依赖项目资源**：只用引擎内置 API
- **文档齐全**：[文字特效手册.md](文字特效手册.md)（50KB，19 个效果 + 参数说明）

## 关键实现笔记

玩这个项目、或者想抄点什么走，这几块比较有意思：

### HUD 版式

所有坐标写在 **1920×1080 设计稿空间**里，运行时按 16:9 等比缩放。改版式只需动 `hud_layout.gd` 顶部的常量：

```gdscript
const STAGE_RECT := Rect2(510.0, 30.0, 900.0, 690.0)   # 画面窗口
const DIALOG_RECT := Rect2(310.0, 740.0, 1290.0, 290.0) # 对话框
```

### 对话框排版

句子可能长达 36 字，所以做了三层保险：

1. `HFlowContainer` 自动折行
2. **宽高双约束**求字号（用 `Font.get_string_size()` 实测，不靠估算）
3. 对话框 `clip_contents = true` 硬保护

实测 163 句 × 2 模式 = **0 句越界**。

### 好感度均分

不给句子固定涨幅，而是：

```gdscript
# 本阶段还差多少好感 ÷ 本阶段还剩几句
var base := (target - affection) / float(sentences_left)
```

这样**无论打快打慢都大致 10 句一阶段**，剧情节奏可控。

### 同心圆跟"阶段"不跟"总量"

```gdscript
func _stage_affection_progress() -> float:
    # 阶段1: 0→1/3, 阶段2: 1/3→2/3, 阶段3: 2/3→100
    # 所以每进新阶段，内圆会重新从小长起
```

### 烛光法线光照

`lighting/` 是从一个 2D 动画原型移植的模块，用**真实法线贴图**驱动光照：

- `sprite_normal_lit.gdshader` — 角色受光
- `ambient_bounce.gdshader` — 背景漫反射
- `candle_film.gdshader` — 全屏胶片滤镜

在 `gl_compatibility` 渲染器下也能正常出图。

## 开发状态

**可玩原型**。三个阶段的画面、剧情、音效、排版都已完成，可以完整通关。

已知可改进的地方：

- 第三阶段的照片序列目前是固定顺序，可以做成"好感度越高，照片里的人越模糊"的渐进效果
- 语音池按句长分类了，但播放时机还可以更细
- 字体子集只含当前文案用到的字，**改剧情文案后需要重新做子集**（否则新字会显示成方框）
